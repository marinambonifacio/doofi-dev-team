## 🚀 Sobre o Projeto

Este projeto foi desenvolvido com foco na construção de interfaces modernas e na simulação de um fluxo completo de autenticação de usuários utilizando a plataforma **FlutterFlow**.

A aplicação contempla desde a entrada do usuário no sistema até sua navegação interna, aplicando boas práticas de UX (experiência do usuário), validação de dados e organização estrutural de páginas.

## ⚙️ Funcionalidades Técnicas

O sistema utiliza **Actions do FlutterFlow** para controle de navegação e interações, incluindo:

- Navegação entre telas (Page Navigation)  
- Ação de ir para outra página  
- Ação de voltar para página anterior  
- Direcionamento interno entre telas do sistema  
- Organização do fluxo de usuário  

Além disso:

- Os botões de **LinkedIn, GitHub e Email** presentes na aplicação realizam o **redirecionamento direto para as respectivas plataformas**, simulando integração com perfis profissionais.

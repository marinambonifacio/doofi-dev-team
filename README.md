## 📌 Descrição do Projeto

Este projeto foi desenvolvido com o objetivo de praticar o uso da plataforma FlutterFlow, explorando a criação de interfaces, navegação entre telas e validação de campos.

A aplicação consiste em um sistema simples com tela de login, cadastro e navegação entre páginas, simulando o fluxo de entrada de um usuário.

## 🎯 Funcionalidades

* Tela de Splash Screen
* Tela de Login
* Tela de Cadastro
* Tela com informações dos integrantes
* Menu lateral (Drawer)
* Navegação entre páginas
* Validação de campos (email, senha, etc.)
* Interações básicas (ex: mostrar/ocultar senha)

## 🧩 Tecnologias Utilizadas

* FlutterFlow (No Code)

## 📄 Estrutura de Páginas

* Página 00: Splash Screen
* Página 01: Login
* Página 02: Cadastro
* Página 03: Integrantes do Grupo

## ✅ Validação de Campos

O projeto implementa validações para garantir que os dados inseridos pelos usuários estejam corretos antes de prosseguir:

* Campos obrigatórios
* Validação de formato de email
* Tamanho mínimo de senha

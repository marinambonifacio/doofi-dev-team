## 🚀 Sobre o Projeto

Este projeto foi desenvolvido com foco na construção de interfaces modernas e na simulação de um fluxo completo de autenticação de usuários utilizando a plataforma **FlutterFlow**.

A aplicação contempla desde a entrada do usuário no sistema até sua navegação interna, aplicando boas práticas de UX (experiência do usuário) e validação de dados.

## 🧠 Funcionalidades

✔ Splash Screen (carregamento inicial)
✔ Tela de Bem-vindo personalizada
✔ Sistema de Login
✔ Sistema de Cadastro
✔ Tela Home (Página principal)
✔ Menu lateral (Drawer Navigation)
✔ Tela de perfil dos integrantes
✔ Navegação entre telas
✔ Validação de campos (email e senha)
✔ Interações dinâmicas (exibição de senha, feedback visual)

---

## 🗂️ Estrutura da Aplicação

| Página        | Descrição                    |
| ------------- | ---------------------------- |
| Splash Screen | Tela inicial de carregamento |
| Bem -vindo    | Tela inicial com botões de Login e Cadastro|
| Cadastro      |  Registro de novo usuário     |
| Login         |  Autenticação do usuário     |
| Home          | Página principal do sistema  |
| Perfis        | Informações de cada integrante |



## 🛠️ Tecnologias Utilizadas

* FlutterFlow (No Code)
* Conceitos de UX/UI Design
* Lógica de validação de formulários

---

## 🔐 Validações Implementadas

* Campos obrigatórios
* Verificação de formato de e-mail
* Definição de tamanho mínimo de senha
* Feedback visual para o usuário
